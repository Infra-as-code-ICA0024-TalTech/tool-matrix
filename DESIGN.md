# Design direction

Purpose: a lecture comparison that lets students isolate infrastructure tools, inspect six scores, and trace them to the supplied slide or demo inventory.

Palette: white #ffffff, ice #f4f7fb, ink #17334b, muted blue #596d7c, orange #c26b24, ochre #9b7900, green #487835. The three series retain the slide's color associations and add distinct line patterns.

Typography: Avenir Next with Segoe UI and sans-serif fallbacks. A compact course heading and a large radar diagram lead; exact values use tabular numerals.

Layout: a filter column beside the diagram, followed by an exact-value table. On phones, filters sit above the diagram and the table scrolls horizontally. Native checkboxes support keyboard selection. A category filter separates infrastructure tools from supporting workflow tools and runtimes.

The radar is the visual focus. No decorative cards, summary rankings, or overall scores. Blank source cells remain unscored, never zero. The supplied image's rankings are a lecture snapshot, not current independent benchmarks.
